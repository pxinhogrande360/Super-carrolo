# Super-Carrolo

Um jogo em que os jogadores têm que girar a garrafa para derrotar o adversário.

## Código-fonte completo

### Como rodar localmente no computador

1. Instale o Node.js (https://nodejs.org/) versão 20+.
2. Abra o terminal na pasta `super-carrolo-codigo`.
3. Execute: `npm install`
4. Para rodar em modo desenvolvimento: `npm run dev`
5. Para gerar a versão final: `npm run build`

### Como publicar online

- **Vercel / Netlify:** conecte este repositório e use o comando de build `npm run build`, com pasta de saída `dist`.
- **GitHub Pages:** execute `npm run build` e publique o conteúdo da pasta `dist`.
